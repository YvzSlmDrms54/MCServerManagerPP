Setting it up

Five minutes, most of it spent locating your server folder.

  1. Download and extract the portable build to a folder of your choice — anywhere on your PC works.
  2. Run the app once. A server folder appears next to the executable, along with a short readme.
  3. Copy your server files — the .jar and an accepted eula.txt — into that server folder. Already running a server elsewhere? Copy the whole thing in.
  4. Press Start. The console will show the server booting up, and the detected server type appears in the top-right corner.
  5. Optional: set up backups, Discord webhooks, and player management from the Tools menu whenever you're ready.
Full walkthroughs for every feature — properties, maintenance mode, scheduled tasks, webhooks — are in the documentation.
