MCServerManager++

One window. Everything you'd otherwise juggle.

No config-file archaeology, no separate Discord bot to babysit. It's the parts of running a server you actually touch.

01

Live console, both ways

Watch server output stream in real time and send commands back without touching a terminal.

02

Backups on a schedule

Pick a time, and the world gets zipped automatically — plus one right before the server closes, just in case.

03

Discord, actually integrated

Wire up webhooks per event — server up, server down, players joining, crashes — each with its own channel and mention.

04

Players, ops, whitelist, bans

Manage everyone who touches your server from one panel instead of four separate commands.

05

Maintenance mode

Lock the server down, kick everyone but staff, and restore the old MOTD automatically when you're done.

06

Crash detection

If the server dies without you telling it to, you'll know immediately — in the console and in Discord.

Works with the server you already run

Drop your existing install in and MCServerManager++ figures out what it's looking at.
